# Tower Evolution Flow Rules

塔进化流程可以理解成一条完整链路：

```text
放置基础塔 -> 战斗积累经验 -> 达到进化条件 -> 玩家打开进化界面 -> 选择分支 -> 支付资源 -> 塔变成新分支 -> 攻击方式和流派效果改变
```

## 1. 放置基础塔

玩家一开始只能建造基础塔，比如：

- 弓箭塔
- 火焰塔
- 魔法塔

这些塔刚放下时没有分支，只是通用版本。

例如弓箭塔：

- 攻击方式：单体射击
- 特点：射程较远，伤害中等
- 当前等级：Lv1
- 当前经验：0/40

此时它还不能进化。

## 2. 塔通过战斗获得经验

塔在战斗中会获得经验。

经验来源可以是：

- 命中敌人
- 击杀敌人
- 参与击杀
- 波次结束存活奖励

| 行为 | 获得经验 |
| --- | --- |
| 命中敌人 | +1 |
| 击杀敌人 | +5 |
| 击杀精英敌人 | +10 |
| 波次结束存活 | +3 |

假设一座弓箭塔在前几波中多次攻击敌人，它的经验会从：

```text
Lv1 0/40
```

成长到：

```text
Lv1 40/40
```

然后升级为：

```text
Lv2 0/60
```

再继续战斗，达到：

```text
Lv3 0/100
```

## 3. 达到进化条件

塔不是一有经验就能进化，而是要满足条件。

推荐进化条件是：

- 塔等级达到 Lv3
- 经验达到指定值，例如 100
- 玩家拥有足够金币
- 当前塔还没有进化过

例如弓箭塔的进化条件：

- 等级达到 Lv3
- 经验达到 100
- 消耗金币 120

满足后，塔详情面板上出现“可进化”提示。

例如：

```text
弓箭塔 Lv3
经验：100/100
状态：可进化
按钮：进化
```

## 4. 玩家打开进化界面

玩家点击塔，再点击“进化”按钮。

此时弹出进化分支界面。

界面中不是直接自动升级，而是让玩家做选择。

以弓箭塔为例，界面中出现两个分支：

```text
弓箭塔可进化为：

[狙击塔]
高伤害 / 远射程 / 优先攻击精英
攻击力大幅提高，攻速降低

[连射塔]
高攻速 / 持续输出 / 清理普通敌人
攻击速度大幅提高，单次伤害降低
```

玩家必须在两个分支中选一个。

## 5. 选择分支

同一个基础塔的两个分支要代表不同玩法。

### 分支 A：狙击塔

适合打高血量敌人。

变化：

- 攻击力提高很多
- 攻击速度变慢
- 射程变远
- 优先攻击生命值最高的敌人
- 对精英敌人有额外伤害

玩法感受：

少量攻击，但每一下很重。适合处理 Boss、精英怪、高血量单位。

### 分支 B：连射塔

适合持续清怪。

变化：

- 单次伤害降低
- 攻击速度大幅提高
- 连续攻击同一目标时攻速越来越快
- 更适合清理普通敌人

玩法感受：

攻击很快，持续压制。适合处理大量小怪。

玩家选择其中一个后，点击“确认进化”。

## 6. 支付资源并完成进化

点击确认后，系统检查：

- 金币是否足够
- 塔是否仍然满足等级要求
- 塔是否还没进化
- 分支配置是否有效

检查通过后：

- 扣除金币
- 替换塔数据
- 更新塔外观
- 更新攻击逻辑
- 播放进化特效
- 关闭进化界面

例如：

```text
弓箭塔 -> 狙击塔
消耗金币：120
```

进化完成后，这座塔就固定为狙击塔，不能再改成连射塔。

## 7. 进化后塔的变化

进化不是简单加攻击力，而是整座塔的定位改变。

以弓箭塔进化为狙击塔为例：

进化前：

- 弓箭塔
- 普通单体攻击
- 优先攻击最前方敌人
- 中等伤害
- 中等攻速

进化后：

- 狙击塔
- 高伤单体攻击
- 优先攻击血量最高敌人
- 攻击前有蓄力
- 对精英敌人额外伤害
- 命中特效更强

如果进化为连射塔：

- 连射塔
- 高频单体攻击
- 连续攻击同一目标会叠加攻速
- 切换目标后叠层重置
- 适合持续压制普通敌人

所以同样是弓箭塔，两个分支的战斗体验不同。

## 8. 指挥官参与联动

进化分支还要和指挥官形成流派。

例如玩家选择“游侠长”。

游侠长强化弓箭类分支：

- 弓箭类分支塔射程 +10%
- 狙击塔对精英伤害额外 +15%
- 连射塔最大连击层数 +2

这样玩家如果走弓箭塔路线，就会形成：

```text
游侠长 + 狙击塔 + 连射塔
```

玩法是：

- 狙击塔负责击杀精英
- 连射塔负责清理小怪
- 游侠长负责标记重点目标
- 所有弓箭分支塔围绕标记目标集火

另一个例子是“炎术师”。

炎术师强化火焰类分支：

- 火焰类分支塔伤害 +10%
- 灼烧持续时间 +1 秒
- 爆炎塔爆炸半径 +10%

这样玩家可以形成：

```text
炎术师 + 爆炎塔 + 灼烧塔
```

玩法是：

- 灼烧塔给敌人挂持续燃烧
- 爆炎塔负责范围爆发
- 炎术师提高火焰伤害和灼烧时间
- 如果再配冰霜塔减速，就能让敌人在燃烧区域停留更久

## 9. 完整例子

一局游戏中，玩家选择游侠长。

第 1 波：

- 玩家建造 2 座弓箭塔
- 弓箭塔攻击小怪，开始获得经验

第 2 波：

- 第一座弓箭塔升到 Lv2
- 攻击力小幅提升

第 3 波：

- 第一座弓箭塔达到 Lv3
- 界面显示“可进化”
- 玩家点击这座塔，看到两个选择：
  - 狙击塔：适合打精英
  - 连射塔：适合清小怪

这时下一波会出现精英敌人，玩家选择狙击塔。

进化后：

- 弓箭塔变成狙击塔
- 攻击变慢
- 射程变远
- 伤害明显提高
- 优先打高血量敌人

第 4 波：

- 精英敌人出现
- 游侠长使用“集火标记”
- 狙击塔优先攻击标记目标
- 精英敌人快速被击杀

之后玩家又把第二座弓箭塔进化成连射塔，用来清普通怪。

最终形成：

- 狙击塔负责精英
- 连射塔负责小怪
- 游侠长负责标记和射程增益

这就是一个初步流派。

## 10. 系统内部流程

从程序角度，塔进化大概是这样：

```text
塔获得经验
↓
检查是否升级
↓
检查是否达到进化条件
↓
如果满足，设置 canEvolve = true
↓
玩家点击进化按钮
↓
打开分支选择 UI
↓
玩家选择 branchId
↓
检查金币、等级、状态
↓
扣除金币
↓
应用分支配置
↓
替换攻击模块
↓
替换特效和图标
↓
标记 hasEvolved = true
```

伪代码：

```csharp
void TryEvolveTower(Tower tower, TowerBranch branch)
{
    if (tower.HasEvolved)
        return;

    if (tower.Level < branch.RequiredLevel)
        return;

    if (tower.Exp < branch.RequiredExp)
        return;

    if (player.Gold < branch.Cost)
        return;

    player.Gold -= branch.Cost;

    tower.ApplyBranch(branch);
    tower.HasEvolved = true;

    PlayEvolveEffect(tower.Position);
    RefreshTowerPanel(tower);
}
```

## 11. 玩家需要感受到什么

塔进化流程最终要让玩家感受到三件事：

第一，塔是“养成出来的”。

不是一开局就直接买高级塔，而是通过战斗积累经验。

第二，进化是“选择方向”。

玩家不是单纯点升级，而是在两个分支之间做策略选择。

第三，分支会影响流派。

玩家选择狙击塔、连射塔、爆炎塔、灼烧塔，不只是数值不同，而是决定整局游戏的打法。
