# Week 3 Requirements: Tower Branch Evolution

## Version Goal

第 3 周的核心目标是让塔防玩法从“放塔打怪”进入“流派构筑”阶段。

本周需要实现基础塔的经验、升级、分支进化、攻击表现差异，以及指挥官与进化分支之间的联动。完成后，玩家应能围绕不同塔分支和指挥官特性形成初步策略，而不是只按数值高低选择塔。

## Core Experience

玩家在一局游戏中可以通过使用基础塔积累经验，并在满足条件后选择进化方向。

同一种基础塔至少拥有两个进化分支，两个分支之间必须有明显玩法差异，例如：

- 单体爆发 vs 群体范围
- 持续伤害 vs 控制减速
- 高频攻击 vs 低频高伤
- 远程点杀 vs 路径覆盖

指挥官“炎术师”和“游侠长”需要分别能强化部分分支，使玩家可以形成两套初步流派。

## Functional Scope

本周需要完成以下系统：

- 塔经验与升级条件
- 塔分支进化选择界面
- 至少 3 种基础塔的分支进化
- 分支后的攻击逻辑差异
- 指挥官与分支塔的联动效果
- 基础攻击特效、命中特效和反馈表现

## Base Tower Evolution Design

| 基础塔 | 分支 A | 分支 B | 设计差异 |
| --- | --- | --- | --- |
| 弓箭塔 | 狙击塔 | 连射塔 | 高伤单体 vs 高频输出 |
| 火焰塔 | 爆炎塔 | 灼烧塔 | 范围爆发 vs 持续伤害 |
| 魔法塔 | 冰霜塔 | 雷链塔 | 控制减速 vs 弹射群伤 |

## Tower Experience And Upgrade Conditions

每座塔需要拥有独立经验值。

经验来源：

- 塔攻击命中敌人时获得少量经验
- 塔击杀敌人时获得额外经验
- 参与击杀可获得部分经验
- 可选：波次结束时存活塔获得少量经验

基础规则建议：

| 行为 | 经验 |
| --- | --- |
| 命中普通敌人 | +1 |
| 击杀普通敌人 | +5 |
| 命中精英敌人 | +2 |
| 击杀精英敌人 | +10 |
| 波次结束存活 | +3 |

进化条件：

- 基础塔达到等级 3
- 或累计经验达到指定值，例如 100
- 玩家支付一定金币进行进化
- 每座塔只能选择一个进化分支
- 已进化塔不能切换分支

等级建议：

| 等级 | 所需经验 | 解锁 |
| --- | --- | --- |
| Lv1 | 0 | 初始 |
| Lv2 | 40 | 小幅属性提升 |
| Lv3 | 100 | 解锁分支进化 |

基础升级效果：

- Lv2：攻击力 +10%，或攻击速度 +5%
- Lv3：攻击力 +15%，解锁进化按钮

## Branch Evolution UI

当塔满足进化条件后，塔详情面板中显示“进化”入口。

点击“进化”后打开分支选择界面。

界面必须包含：

- 当前基础塔名称、等级、经验
- 两个进化分支选项
- 每个分支的名称
- 每个分支的核心玩法标签
- 属性变化预览
- 特殊效果说明
- 进化消耗
- 确认按钮
- 返回按钮

示例界面信息：

狙击塔：

- 标签：单体、高伤、优先精英
- 攻击力大幅提升
- 攻击速度降低
- 优先攻击生命值最高的敌人
- 对精英敌人造成额外伤害

连射塔：

- 标签：高频、多段、清杂
- 攻击力略降
- 攻击速度大幅提升
- 连续攻击同一目标时逐渐提高攻速

交互要求：

- 玩家点击分支时，高亮当前选择
- 点击确认后完成进化
- 进化后塔模型、图标、攻击表现需要变化
- 不满足金币时确认按钮置灰，并显示金币不足

## Archer Tower Branches

基础定位：

- 单体物理输出
- 攻速中等
- 射程较远
- 适合作为早期主力塔

### Sniper Tower / 狙击塔

玩法定位：

- 高伤害单体点杀
- 优先处理精英和高血量敌人

属性变化：

- 攻击力大幅提升
- 攻击速度降低
- 射程提升
- 攻击目标优先级改为最高生命值敌人

特殊效果：

- 对精英敌人造成额外伤害
- 攻击有短暂蓄力表现
- 命中时显示强力命中特效

推荐数值：

- 攻击力：基础弓箭塔的 250%
- 攻速：基础弓箭塔的 55%
- 射程：基础弓箭塔的 120%
- 对精英伤害：+30%

### Rapid Shot Tower / 连射塔

玩法定位：

- 高频单体输出
- 适合清理普通敌人
- 依赖持续输出

属性变化：

- 单次攻击力降低
- 攻击速度大幅提升
- 射程略降

特殊效果：

- 连续攻击同一目标时，攻速逐步提升
- 切换目标后攻速层数重置
- 命中特效表现为连续箭矢

推荐数值：

- 攻击力：基础弓箭塔的 70%
- 攻速：基础弓箭塔的 220%
- 射程：基础弓箭塔的 90%
- 连击层数：最多 5 层
- 每层攻速：+6%

## Flame Tower Branches

基础定位：

- 范围魔法输出
- 攻速较慢
- 适合处理密集敌人

### Blast Flame Tower / 爆炎塔

玩法定位：

- 高爆发范围伤害
- 适合处理成群敌人

属性变化：

- 攻击力提升
- 攻击速度降低
- 爆炸半径提升

特殊效果：

- 攻击命中后产生范围爆炸
- 爆炸中心伤害最高，边缘伤害衰减
- 命中时有明显爆炸反馈

推荐数值：

- 攻击力：基础火焰塔的 180%
- 攻速：基础火焰塔的 70%
- 爆炸半径：基础火焰塔的 140%
- 边缘伤害：中心伤害的 60%

### Burning Tower / 灼烧塔

玩法定位：

- 持续伤害
- 适合与减速、聚怪效果配合

属性变化：

- 直接伤害降低
- 攻速略微提升
- 附加持续燃烧效果

特殊效果：

- 命中敌人后施加灼烧
- 灼烧期间每秒受到火焰伤害
- 灼烧效果可刷新持续时间
- 多座灼烧塔不无限叠加，最多叠加指定层数

推荐数值：

- 直接伤害：基础火焰塔的 75%
- 攻速：基础火焰塔的 110%
- 灼烧持续时间：4 秒
- 每秒伤害：基础攻击力的 25%
- 最大灼烧层数：3 层

## Magic Tower Branches

基础定位：

- 稳定魔法输出
- 中等射程
- 中等攻速
- 适合作为功能型塔基础

### Frost Tower / 冰霜塔

玩法定位：

- 控制减速
- 辅助其他输出塔

属性变化：

- 攻击力降低
- 攻击附带减速
- 攻击范围略微提升

特殊效果：

- 命中敌人后降低移动速度
- 减速持续一段时间
- 多次命中可刷新持续时间
- 可对小范围敌人造成轻微溅射减速

推荐数值：

- 攻击力：基础魔法塔的 65%
- 攻速：基础魔法塔的 90%
- 减速比例：30%
- 减速持续时间：2 秒
- 溅射半径：小范围

### Chain Lightning Tower / 雷链塔

玩法定位：

- 弹射群体伤害
- 适合处理中等密度敌群

属性变化：

- 攻击力略降
- 攻击可在多个敌人之间跳跃
- 每次跳跃伤害递减

特殊效果：

- 攻击命中后弹射至附近敌人
- 同一次攻击不能重复命中同一敌人
- 弹射目标数量有限
- 弹射时显示闪电链特效

推荐数值：

- 初始伤害：基础魔法塔的 90%
- 最大弹射次数：3 次
- 每次弹射伤害衰减：20%
- 弹射搜索范围：中等

## Commander Synergy

本周至少实现炎术师和游侠长两名指挥官与塔分支的基础联动。

### 炎术师

流派定位：

- 强化火焰塔分支
- 偏范围伤害、持续灼烧、爆发清场

联动对象：

- 爆炎塔
- 灼烧塔
- 可选：所有带燃烧标签的塔

被动效果建议，炎术共鸣：

- 火焰类分支塔伤害 +10%
- 灼烧持续时间 +1 秒
- 爆炎塔爆炸半径 +10%

主动技能建议，烈焰号令：

- 持续 8 秒
- 所有火焰分支塔攻击速度 +20%
- 灼烧塔立即刷新目标身上的灼烧时间
- 爆炎塔下一次攻击造成额外范围伤害

形成流派：

- 灼烧塔负责持续铺火
- 冰霜塔或其他控制塔延长敌人停留时间
- 爆炎塔负责清理成群敌人
- 炎术师增强燃烧持续收益

### 游侠长

流派定位：

- 强化弓箭塔分支
- 偏单体点杀、高频输出、精英处理

联动对象：

- 狙击塔
- 连射塔
- 可选：所有物理远程塔

被动效果建议，鹰眼指挥：

- 弓箭类分支塔射程 +10%
- 狙击塔对精英伤害额外 +15%
- 连射塔最大连击层数 +2

主动技能建议，集火标记：

- 标记当前生命值最高的敌人，持续 6 秒
- 狙击塔优先攻击被标记目标
- 连射塔攻击被标记目标时连击层数增长速度翻倍
- 被标记目标受到弓箭类分支塔伤害 +20%

形成流派：

- 狙击塔负责击杀精英和高血量敌人
- 连射塔负责快速清理普通敌人
- 游侠长通过标记机制统一输出目标
- 玩家围绕“点杀核心目标”建立策略

## Attack Feedback Requirements

进化后不能只改数值，必须在攻击行为和视觉反馈上体现差异。

| 分支 | 行为差异 | 表现差异 |
| --- | --- | --- |
| 狙击塔 | 蓄力高伤，优先高血量 | 粗箭矢/亮光命中 |
| 连射塔 | 高频连续射击 | 多发箭矢、快速音效 |
| 爆炎塔 | 大范围爆炸 | 火焰爆炸特效 |
| 灼烧塔 | 持续 DOT | 敌人身上燃烧特效 |
| 冰霜塔 | 减速控制 | 冰蓝命中、减速状态图标 |
| 雷链塔 | 弹射攻击 | 闪电链连接多个敌人 |

## Data Configuration

塔分支建议使用配置驱动，避免硬编码。

每个塔分支至少需要配置：

- 塔 ID
- 显示名称
- 基础塔 ID
- 分支 ID
- 图标
- 模型或外观引用
- 攻击力
- 攻击速度
- 射程
- 攻击类型
- 目标选择规则
- 特殊效果列表
- 进化消耗
- 需求等级
- 需求经验
- 标签列表

示例字段：

```json
{
  "id": "archer_sniper",
  "baseTowerId": "archer",
  "name": "狙击塔",
  "branch": "sniper",
  "requiredLevel": 3,
  "requiredExp": 100,
  "evolveCost": 120,
  "damageMultiplier": 2.5,
  "attackSpeedMultiplier": 0.55,
  "rangeMultiplier": 1.2,
  "targetPriority": "HighestHealth",
  "tags": ["Physical", "Archer", "SingleTarget"],
  "effects": [
    {
      "type": "BonusDamageToElite",
      "value": 0.3
    }
  ]
}
```

## Acceptance Standards

本周功能完成后，需要满足以下标准：

- 至少 3 种基础塔可以进化。
- 每种基础塔至少有 2 个分支。
- 同一基础塔的两个分支必须有明显玩法差异。
- 塔可以通过经验或等级满足进化条件。
- 玩家可以在界面中选择分支并完成进化。
- 进化后塔的属性、攻击逻辑、视觉表现发生变化。
- 炎术师可以强化火焰相关分支，形成初步火焰流派。
- 游侠长可以强化弓箭相关分支，形成初步远程点杀流派。
- 至少实现基础命中特效、进化特效、状态反馈。
- 一局游戏内玩家能实际体验到“选择不同分支导致打法不同”。

## Test Cases

基础测试：

- 放置弓箭塔，攻击敌人后经验增加。
- 弓箭塔达到 Lv3 后出现进化入口。
- 金币不足时无法进化。
- 金币足够时可以选择狙击塔或连射塔。
- 选择狙击塔后不能再切换为连射塔。

分支差异测试：

- 狙击塔优先攻击高生命值敌人。
- 连射塔攻击频率明显高于狙击塔。
- 爆炎塔可以对多个敌人造成范围伤害。
- 灼烧塔可以给敌人施加持续伤害。
- 冰霜塔可以降低敌人移动速度。
- 雷链塔可以弹射攻击多个敌人。

指挥官测试：

- 选择炎术师时，灼烧塔持续时间增加。
- 选择炎术师时，爆炎塔范围或伤害提升。
- 选择游侠长时，狙击塔对精英伤害提升。
- 选择游侠长时，连射塔连击层数上限提升。
- 使用游侠长主动技能后，弓箭分支塔会优先攻击标记目标。

## Definition Of Done

当玩家在实机流程中能够完成以下体验时，本周视为完成：

玩家放置基础塔，塔通过战斗积累经验，达到条件后打开进化界面，从两个分支中选择一个方向。进化后的塔在攻击方式、目标选择、视觉反馈和战斗价值上明显不同。玩家选择炎术师时能围绕火焰分支构筑，选择游侠长时能围绕弓箭分支构筑。
